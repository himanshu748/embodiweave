The robot hit a pedestrian. A graph chose the fix.

EmbodiWeave turns a failing robot policy into an evidence-backed training decision. An agent queries a FalkorDB graph of checkpoints, contracts, evaluations, failures and past adaptation trials, picks where to start training (or decides to start from scratch), runs real PPO, measures the result and asks a promotion gate whether it may ship.

How it works

Six bounded steps from failure to a gated fix

The LLM picks each tool call over MCP. Trusted code enforces contracts, budgets and the gate, and every outcome is written back to the graph.

  1. 1ObserveMeasured failures of the deployed policy. Authored hypotheses stay labelled as hypotheses.
  2. 2QueryRead-only Cypher templates over lineage, semantic contracts and matched validation.
  3. 3DecideA frozen rule ranks every parent and scratch by conditioned transfer history, then records why.
  4. 4TrainOne bounded PPO run from the chosen start. No retries to chase a better number.
  5. 5MeasureRetained-behaviour suites, tied to the exact artifact hash of the new checkpoint.
  6. 6GatePromotion only if every suite clears its threshold. The verdict joins the graph.

    Graph model

    Evidence lives in FalkorDB, decisions read it

    Authored world facts plus measured evidence appended from immutable records. Hover or focus a node to trace its relationships.

    One of the decision queries

    Which past trials from each candidate parent apply to this exact target, recipe, budget and contract.

    UNWIND $ids AS pid
MATCH (p:Policy {id:pid})
OPTIONAL MATCH (t:Trial)-[:FROM_PARENT]->(p)
WHERE t.threshold_id = $threshold
  AND t.recipe = $recipe AND t.budget = $budget
  AND (t)-[:TARGETS]->(:Family {id:$family})
  AND (t)-[:UNDER_CONTRACT]->(:Contract {id:$contract})
OPTIONAL MATCH (t)-[:PRODUCED]->(child:Policy)
RETURN pid AS policy_id, t.id AS trial_id,
       t.threshold_reached AS reached,
       t.steps_to_threshold AS steps_to_threshold,
       child.id AS child_id

    Why a graph

    • Transfer history is conditional. A past trial only counts if its target family, recipe, budget, threshold and contract all match, which is a multi-hop pattern, not a row filter.
    • Contracts gate reuse. A checkpoint with a different ray order is rejected before ranking, with the differing fields named.
    • Every decision is provenance. The decision records the graph revision and the exact queries it read, so it can be replayed.
    • All 10 agent query templates are read-only and run through GRAPH.RO_QUERY, so the agent cannot write the graph.
