Your robot failed.
The graph decides the fix.

EmbodiWeave turns a failing robot policy into an evidence-backed training decision. An agent queries a FalkorDB graph of checkpoints, contracts, evaluations, failures and past adaptation trials, picks where to start training (or decides to start from scratch), runs real PPO, measures the result and asks a promotion gate whether it may ship. Every outcome is written back, so the next decision changes when the evidence does.

The failure-to-fix loop

Six bounded steps. The LLM chooses which tool to call; trusted code enforces contracts, budgets and the gate.

  1. ObserveMeasured failures of the deployed policy, with authored hypotheses labelled as hypotheses.
  2. QueryRead-only Cypher templates over lineage, semantic contracts and matched validation.
  3. DecideA frozen rule ranks parents and scratch by conditioned transfer history, then records the decision.
  4. TrainOne bounded PPO run from the selected start. No retries to chase a better number.
  5. MeasureEvaluate on retained-behaviour suites tied to the exact artifact hash.
  6. GatePromotion passes only if every suite clears its threshold. Results flow back into the graph.

One of the decision queries

Which past trials from each candidate parent apply to this exact target, recipe, budget and contract.

UNWIND $ids AS pid
MATCH (p:Policy {id:pid})
OPTIONAL MATCH (t:Trial)-[:FROM_PARENT]->(p)
WHERE t.threshold_id = $threshold AND t.recipe = $recipe
  AND t.budget = $budget
  AND (t)-[:TARGETS]->(:Family {id:$family})
  AND (t)-[:UNDER_CONTRACT]->(:Contract {id:$contract})
OPTIONAL MATCH (t)-[:PRODUCED]->(child:Policy)
RETURN pid AS policy_id, t.id AS trial_id,
       t.threshold_reached AS reached,
       t.steps_to_threshold AS steps_to_threshold,
       child.id AS child_id

Graph-driven, not graph-decorated

Remove the transfer history and the decision changes. The no-history arm exists to show it.

Honest by construction

Final-test suites are invisible to the agent, spent suites are refused in code and every number links to a record.
